📊 Sincronizar con Google Sheets

Cada tique guardado se añade automáticamente a tu hoja de cálculo.

Cómo configurar Google Sheets (5 min)
1. Crea una hoja en Google Sheets con nombre Compras
2. Ve a Extensiones → Apps Script
3. Pega el código de abajo y guarda (Ctrl+S)
4. Clic en Implementar → Nueva implementación
5. Tipo: Aplicación web · Acceso: Cualquier usuario
6. Autoriza, copia la URL y pégala arriba ↑
Código Apps Script
function doPost(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName("Compras")
              || ss.getActiveSheet();
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["Fecha","Supermercado",
      "Producto","Categoría","Unidades",
      "Precio Unidad","Total Línea","Ticket ID"]);
  }
  var data = JSON.parse(e.postData.contents);
  data.rows.forEach(function(r) {
    sheet.appendRow([r.date,r.store,r.product,
      r.category,r.qty,r.unitPrice,
      r.totalLine,r.ticketId]);
  });
  return ContentService
    .createTextOutput(JSON.stringify({status:"ok"}))
    .setMimeType(ContentService.MimeType.JSON);
}
function doGet() {
  return ContentService
    .createTextOutput("API ok")
    .setMimeType(ContentService.MimeType.TEXT);
}
